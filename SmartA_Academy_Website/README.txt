# SmartA Academy Website

## Files
- `index.html` — website structure and content
- `style.css` — black-and-gold styling and responsive layout
- `script.js` — mobile navigation, course enquiry links, current year, and email form behavior

## Run in VS Code
1. Extract `SmartA_Academy_Website.zip`.
2. Open the extracted `SmartA_Academy_Website` folder in Visual Studio Code.
3. Open `index.html` in a browser, or install the VS Code extension **Live Server**.
4. If using Live Server, right-click `index.html` and choose **Open with Live Server**.

## Edit your details
- Search `index.html` for `+91 9789783876` and `sridevi122000@gmail.com` to update contact details.
- Update course descriptions, availability, or wording directly in `index.html`.
- Colors are defined at the top of `style.css` in `:root`.

## Contact form note
The form uses `mailto:` and opens the visitor's default email app with a prepared message. It does not save enquiries in a database and may not work if the visitor has no email app configured. For a live production site, connect a backend or a form service and test it before publishing.

## Publish
You can publish static files using GitHub Pages, Netlify, or another static hosting provider. Upload `index.html`, `style.css`, and `script.js` together.
